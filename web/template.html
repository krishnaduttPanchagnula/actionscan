How to read this report

Severity

  • CRITICAL — the action is known-compromised or malicious. Remove it and rotate any credential it could read.
  • HIGH — a published advisory covers this exact ref. Upgrade past the advisory's fixed version.
  • MEDIUM — pinning hygiene: the reference is mutable (no ref or a short SHA). Pin it.
  • LOW — outdated but not known-vulnerable. Update when convenient.

Category

  • malicious — matched a compromised/malicious action feed.
  • vulnerable — matched a GitHub Security Advisory version range.
  • osv — matched an OSV.dev advisory for the action's package.
  • outdated — a newer release of the action exists.
  • unpinned — the reference is mutable (no ref, or a short SHA).

Reading a row

  • Repository — the repo that uses the action. Workflow and job point at the exact file and job to open.
  • Issue — why it was flagged, plus the advisory ID when one applies.
  • Recommended fix — a paste-ready uses: line gets a Copy button; prose guidance does not.
